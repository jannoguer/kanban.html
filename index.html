Help

Tasks move left to right through the columns. Everything is saved in this browser only, and other open tabs of the board stay in sync.

Mouse

  • Click empty space in a column to add a task there.
  • Click a card to edit or delete it. A deletion can be undone for 5 seconds.
  • Drag a card to move it to another column or another place in its column.
  • Click the board name to rename it.
  • Search matches titles and descriptions. While searching, each column shows its matches out of its total.
  • Export downloads every task as a JSON file. Import replaces every task with the ones in such a file. The board name and theme are not included.
  • The address ends in #help, #new or a task's id while that dialog is open, so it can be bookmarked and reopens on reload.
