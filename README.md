# kanban.html

A keyboard-only kanban board in a single page, with no dependencies and no build.

Data is saved in localStorage or in exported JSON files on your machine. You can try it by downloading `kanban.html` and opening it in a browser, or use it online at [jannoguer.github.io/kanban.html/kanban.html](https://jannoguer.github.io/kanban.html/kanban.html).
